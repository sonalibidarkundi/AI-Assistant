# Intucate AI Assistant

An AI-powered educational assistant built as part of the Intucate Full-Stack Developer Case Study.

## 🚀 Features

- Ask a single educational question
- Ask multiple questions at once
- Asynchronous processing for multiple questions
- AI-generated educational responses
- Prompt templates stored in MongoDB
- Question and response history stored in MongoDB
- REST API using Flask
- Responsive web frontend
- CORS enabled for frontend-backend communication

## 🛠️ Technologies Used

### Backend
- Python 3.14
- Flask
- MongoDB Atlas
- PyMongo
- Groq API
- Flask-CORS

### Frontend
- HTML
- CSS
- JavaScript
